# Call Monitoring - Frontend

Aplikasi frontend untuk Call Monitoring, dibangun menggunakan Vue.js.

## Prasyarat

Pastikan Anda telah menginstal Node.js di sistem Anda.

## Cara Menjalankan Aplikasi

1. Clone repositori ini.
2. Buka terminal dan arahkan ke direktori proyek (`cd call-monitoring-fe`).
3. Instal semua dependensi dengan menjalankan perintah:
   ```bash
   npm install
   ```
4. Jalankan development server dengan perintah:
   ```bash
   npm run dev
   ```
5. Buka browser dan akses URL yang ditampilkan di terminal (`http://localhost:5173`).
